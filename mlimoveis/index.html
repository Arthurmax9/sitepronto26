Previsão de Preços de Imóveis

Este projeto utiliza Regressão Linear Simples com Scikit-learn para modelar a relação entre o tamanho de um imóvel (m²) e seu preço de mercado.

  • ✓ Geração e simulação de dados com NumPy
  • ✓ Visualização com Matplotlib (dispersão + linha de tendência)
  • ✓ Treinamento do modelo com LinearRegression
  • ✓ Predição de novos valores com base no modelo treinado

Aplicação real: esse tipo de modelo pode ser adaptado para imobiliárias, marketplaces e sistemas de precificação automática, ajudando a estimar valores de forma rápida e consistente.
